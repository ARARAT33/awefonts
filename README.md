# AWEFonts\n\nStatic font library and local pixel font studio. No Workers, Functions, backend, database, login or API keys. Google Fonts delivers the live font files. The browser font studio exports local TTF files and saves drafts in localStorage. Static hosting cannot accept uploads, so public font publishing is intentionally unavailable.\n\nDeploy on Cloudflare Pages with no build command and output directory `/`. Add `fonts.aweconnect.dpdns.org` and `fonts.api.aweconnect.dpdns.org` as custom domains on the same Pages project. The API hostname serves static JSON at `/api/v1/fonts.json`.\n\nCheck each upstream font license before commercial use. The catalog is an index, not a redistribution of font binaries.\n

Last static build trigger: 2026-11-22. No server-side runtime is required.
